braidio.sources

Segment sources: resolve a reference to a cuttable [start, end] window.

A production weaves in extracted segments of source media. How a reference (a lyric quote, an audiobook passage, a news phrase, an SFX cue) maps to a concrete [start, end] span of a source asset is pluggable via the SegmentSource protocol — the weave engine never needs to know it is lyrics.

This module ships one generic implementation: TimedLineSegmentSource, a token-F1 matcher over time-aligned lines (TimedLine). It answers a reference by the best contiguous run of lines — handling exact, sub-line, and multi-line references. Consumers bind it to their own timed lines + asset (e.g. Hamilton binds LRCLIB line timings + owned song audio).

Also provides the lower-level resolver (find_segment(), load_timing()) and the resolve-and-cut convenience (cut_quote()) used directly by the Hamilton pilot; new code should prefer the SegmentSource protocol + braidio.weave.extract_padded().

braidio.sources.find_segment(lines: list[TimedLine], quote: str, *, max_span: int = 12, min_score: float = 0.5, song_end_s: float | None = None) → Segment | None[source]

Best contiguous run of timed lines matching quote, or None.

Scores every run lines[i..j] (up to max_span lines) by token F1 against the reference’s tokens and returns the highest-scoring run clearing min_score. Handles single-line, sub-line, and multi-line references.
