# braidio commentary style library

Style guidance the writing agent routes to — so commentary avoids rhetorical
emptiness and can borrow real critical voices (each shaping BOTH *how* the host
writes and *what* it pays attention to).

- **[anti-platitude-checklist.md](anti-platitude-checklist.md)** — paste-in DO-NOTs for a writer prompt
